# 출생지 좌표 데이터 출처

- 자료: [Open Admin Data – South Korea Administrative Divisions](https://github.com/open-admin-data/south-korea-administrative-divisions)
- 라이선스: **CC BY 4.0** (출처 표시)
- 이용 항목: 전국 17개 시·도, 225개 시·군·구 및 대표 경도 (자료에 없는 지역은 직접 경도 입력)
- 가공: 명칭 정리(강원특별자치도, 전북특별자치도), 시·도별 목록 구성, 반올림 없이 원본 경도 유지
- 주의: 행정구역 **대표 중심점** 자료로 병원·가정의 정확한 출생 지점과 다를 수 있음. 데이터 누락/행정구역 개편 가능성이 있어 직접 경도를 입력할 수 있게 함.
- 사용 사이트: https://leso12.github.io/saju/
